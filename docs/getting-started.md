# 开始使用拾语

[返回首页](../README.md) · [隐私与备份](privacy.md)

## 先体验，再决定

打开应用后，点击「先看看示例」。示例是虚构内容，不调用 API，不产生模型费用。你可以先调整配色和字号，看看是否适合自己的阅读习惯。

## 带回旧对话

1. 从 DeepSeek 导出自己的数据，保留原始 ZIP。
2. 在拾语点击「导入对话」，直接选择 ZIP，无需手动解压。
3. 检查识别出的标题与消息数量，勾选想保留的会话后确认导入。
4. 打开对话，查看内容是否符合预期；重要旧记录请保留原始副本。

导入只在设备上解析，不会自动调用模型。无法读取的文件会列出原因。重复导入会新增记录，目前不自动去重。

支持未加密的常见 ZIP（Stored/Deflate）、单会话 JSON、通用 messages JSON、TXT、MD 和拾语备份。TXT/MD 会作为一条用户消息导入，不会自动区分问答双方。

ZIP 最大 64 MB、最多 500 个会话；单文件解压后最多 20 MB，累计最多 100 MB。不支持分卷、ZIP64 和加密 ZIP；旧浏览器可能需要先解压后导入 JSON。单会话上限为 10000 条消息。

只读取 `chat_sessions` 中的当前分支文字，附件、其他分支、思考和工具结果不会完整导入。不要选择 `user.json`、`manifest.json` 或 `chat_session_index.json` 作为单会话文件。

## 让续聊有依据

在「记忆卡」写下人物关系、重要经历、希望保留的语气和当前停点。保存并启用后，记忆卡会随下一次请求发送给 DeepSeek。

每次最多发送最近 20 条完整消息、最多 4 万字符历史，加上启用的手动记忆（最多 2 万字符）。更早的记录仍可在本机查看，但不会自动全部提供给模型，也不会自动总结。点击「查看发送内容」可以确认实际内容。

## 连接模型

在自己的页面打开「设置与管理 → 连接与 API 设置」，填写自己的 DeepSeek API Key，测试连接后点击「使用此 Key」。不要把 Key 发到 GitHub Issue 或交给其他人。

Key 默认仅存于页面内存，刷新或关闭后需重新填写；可在连接设置中选择「在此设备加密保存 Key」，用独立密码保存，刷新后输入密码解锁。密码不会保存，忘记后需删除密文并重新填写 Key；清除网站数据会删除密文。模型固定为 `deepseek-flash`，可用输入区的「深度思考」开关切换。关闭时最多 4096、开启时最多 8192 输出 token（含思考）。思考与联网默认关闭，可分别直接点击切换；切换对话或刷新后关闭。API 独立计费，以官方账单为准。

「设置与管理 → 用量与余额」汇总本机现存消息的已记录用量，并允许主动查询官方余额。本机统计不等于账户总账单。

## 备份与恢复

在「设置与管理 → 备份与恢复」导出加密备份，保存密码。忘记密码无法恢复。恢复会新增导入，不覆盖已有记录。备份不含 API Key；主题和本机授权需另外设置。

新设备、新浏览器、新域名会使用独立存储。先在旧环境导出，再到新环境导入。不要为了更新页面而清除网站数据。

## 遇到问题

先记录操作、报错文字、浏览器版本。请用 `examples/示例导入.json` 或自行编写的虚构内容复现，不上传私人对话、真实 Key、账单或账户截图。

## 图片、语音与联网

- **图片**：输入框下方选择「图片」，预览或移除后发送；支持 JPEG、PNG、WebP、GIF，GIF 只取一帧。每条消息最多 4 张，原图每张不超过 8 MB、边长不超过 8192 像素；本地缩放至最长边 1536 像素并重新编码。发送的处理后图片会保存在对话与 v2 备份中。图片理解不等于生成图片。
- **语音**：点击「语音 → 开始录音」，需要 HTTPS 和麦克风权限，最长 115 秒。结束后试听，确认「转成文字」才会上传并计费；转写放回草稿，检查后再发送。关闭窗口会丢弃音频。
- **朗读**：完整 AI 回复旁点击「朗读」即生成并播放，再点可停止或取消生成。默认 Tide 男声，已有声音偏好会保留；在「设置与管理 → 图片、语音与联网」中可切换 Stella 女声。文字会发送给 DeepSeek，API 单独计费。同一段音频在本页可重复播放；切换对话、重新渲染消息或关闭页面后释放，不进入备份。
- **联网**：默认关闭。点击「联网」直接开启或关闭，模型按需搜索与读取网页；回复中的编号和「来源与参考」可打开原网页。切换对话或刷新后关闭。联网关闭时不会回传旧网页工具记录；旧回答文字仍可作为近期上下文。

以上入口不需要高级授权，但图片 token、语音、搜索和网页读取由官方计费。本设备 token 统计不包括全部工具费用，请以官方账单为准。

新版本仍只从官方 ZIP 导入当前分支文字，不会因支持新发图片而自动恢复 ZIP 中的历史附件。

## 自行部署的免费授权

本地启动或自行部署后，基础功能可直接使用。需要全文与记忆搜索、保存和套用记忆模板时，在「设置与管理 → 高级功能 · 授权」下载并导入 **社区免费授权.license**。授权只在此浏览器此站点保存，刷新后会重新验签；更换设备或域名后需要重新导入。

运营者提供的站点使用独立验签公钥，只接受该运营者签发的 license。社区免费授权和旧测试授权不能用于这些站点。旧测试授权不再用于当前版本；授权失效不会删除你的聊天、记忆或模板。

在「记忆卡」中可填写当前对话的「回复显示名称」，最多 40 个字符；留空显示「拾语 · Afterword」。显示名称随对话备份保存，不会自动写入模型提示或改变人物设定。

侧边栏每段对话右侧的「…」菜单提供重命名、置顶 / 取消置顶、单独导出（明文 JSON 或加密备份）和删除。删除会再次确认，且不会删除其他对话；单独备份同样不包含 Key。发送范围不再常驻输入框上方，可在「查看发送内容」中查看实际消息与范围限制。
