# 开始使用拾语

[返回首页](../README.md) · [隐私与备份](privacy.md)

## 先体验，再决定

打开应用后，点击「先看看示例」。示例是虚构内容，不调用 API，不产生模型费用。你可以先调整配色和字号，看看是否适合自己的阅读习惯。

## 带回旧对话

1. 从 DeepSeek 导出自己的数据，保留原始 ZIP。
2. 在拾语点击「导入对话」，直接选择 ZIP，无需手动解压。
3. 检查识别出的标题与消息数量，勾选想保留的会话后确认导入。
4. 打开对话，查看内容是否符合预期；重要旧记录请保留原始副本。

导入只在设备上解析，不会自动调用模型。无法读取的文件会列出原因。重复导入会新增记录，目前不自动去重。

支持未加密的常见 ZIP（Stored/Deflate）、单会话 JSON、通用 messages JSON、TXT、MD 和拾语备份。TXT/MD 会作为一条用户消息导入，不会自动区分问答双方。

ZIP 最大 64 MB、最多 500 个会话；单文件解压后最多 20 MB，累计最多 100 MB。不支持分卷、ZIP64 和加密 ZIP；旧浏览器可能需要先解压后导入 JSON。单会话上限为 10000 条消息。

只读取 `chat_sessions` 中的当前分支文字，附件、其他分支、思考和工具结果不会完整导入。不要选择 `user.json`、`manifest.json` 或 `chat_session_index.json` 作为单会话文件。

## 让续聊有依据

在「记忆卡」写下人物关系、重要经历、希望保留的语气和当前停点。保存并启用后，记忆卡会随下一次请求发送给 DeepSeek。

每次最多发送最近 20 条完整消息、最多 4 万字符历史，加上启用的手动记忆（最多 2 万字符）。更早的记录仍可在本机查看，但不会自动全部提供给模型，也不会自动总结。点击「查看发送内容」可以确认实际内容。

## 连接模型

在自己的页面打开「设置与管理 → 连接与 API 设置」，填写自己的 DeepSeek API Key，测试连接后点击「使用此 Key」。不要把 Key 发到 GitHub Issue 或交给其他人。

Key 仅存于页面内存，刷新或关闭后需重新填写。模型固定为 `deepseek-flash`、非思考模式，单次输出上限为 4096 token。API 独立计费，以官方账单为准。

「设置与管理 → 用量与余额」汇总本机现存消息的已记录用量，并允许主动查询官方余额。本机统计不等于账户总账单。

## 备份与恢复

在「设置与管理 → 备份与恢复」导出加密备份，保存密码。忘记密码无法恢复。恢复会新增导入，不覆盖已有记录。备份不含 API Key；主题和本机授权需另外设置。

新设备、新浏览器、新域名会使用独立存储。先在旧环境导出，再到新环境导入。不要为了更新页面而清除网站数据。

## 遇到问题

先记录操作、报错文字、浏览器版本。请用 `examples/示例导入.json` 或自行编写的虚构内容复现，不上传私人对话、真实 Key、账单或账户截图。
