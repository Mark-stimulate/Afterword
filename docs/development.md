
Node.js 22+，没有第三方运行依赖。36 项自动化测试使用合成数据，不能替代真实浏览器、移动端与 API 联调。

## 保持的约定

- Key 仅保存在页面内存，不写入数据库、备份或日志。
- 网络请求只直连 DeepSeek 官方 API，不引入代理或统计 SDK。
- 文本按纯文本渲染；导入预览后才持久化。
- 更改目录、品牌或构建方式时，保留旧存储和备份标识的兼容性。
- 数据访问、基础导出、删除和安全保护始终免费。
- `LICENSE` 保留原版权声明，不随品牌重命名删除原署名。

## 0.3.0 多媒体

`src/media.mjs` 放请求、引用、备份图片校验与 WAV 编码等纯函数；`src/browser-media.mjs` 处理图片本地重编码和录音；`src/recorder-worklet.js` 捕获单声道 PCM；`src/media-ui.mjs` 管理窗口、预览、播放与取消。所有新增网络请求固定直连 `api.deepseek.com`，不需要新运行依赖。

联网关闭时不声明工具，也不回传旧 `server_tool_calls`。开启时保留完整工具记录以支持网页上下文，并通过 `annotations` 的 Unicode 码点位置展示引用。仅将 HTTP(S) 来源渲染为文字链接，不执行模型 HTML，不自动加载远程资源。

聊天备份 v2 保留图片与引用，兼容旧 v1 导入；内部数据库名未变。测试使用合成图片、音频和流式事件，不应加入真实 Key 或用户记录。浏览器模拟验证不代表生产接口或全部手机已经实测。

品牌显示统一使用 **拾语 · Afterword**；仓库、包名和导出文件使用小写 `afterword`。CI 会检查并阻止英文名称的大小写混用。

## 授权模型

应用只有一套功能代码。所有高级操作统一检查有效的已验签 license，没有按构建类型直接解锁的分支。`src/build-config.mjs` 是公开社区验签配置；免费 license 位于 `examples/`。基础数据访问和保护不依赖授权。

构建配置选择验签公钥和授权类型；运行时会同时校验签名、产品、功能级别、主版本、类型与有效期。社区免费授权不包含到期日，适用于 0.x；更换公钥或类型后，浏览器已保存的授权必须重新通过验证。测试覆盖跨配置拒绝、旧测试授权拒绝、过期与错误构建配置。

离线验签不能阻止用户修改自己部署的开源客户端，也不提供服务器撤销、强反破解或支付能力。许可证文件不是 API Key，代码的 MIT 许可证与功能解锁 license 是不同概念。
