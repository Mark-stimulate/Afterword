## 目录

| 目录 / 文件 | 用途 |
| --- | --- |
| `src/` | 原生 HTML、CSS、JS 应用与核心模块 |
| `scripts/` | 本机服务器、静态构建和社区版生成脚本 |
| `tests/` | 导入、上下文、加密、授权、主题和 ZIP 测试 |
| `examples/` | 虚构导入样例与公开测试许可证 |
| `docs/` | 使用、隐私、部署和开发文档，以及品牌封面 |
| `.github/workflows/` | GitHub 自动测试与构建 |
| `dist/`、`community/` | 自动生成，不提交版本库 |

## 验证

```bash
npm test
npm run build
npm run build:community
```

Node.js 22+，没有第三方运行依赖。18 项自动化测试使用合成数据，不能替代真实浏览器、移动端与 API 联调。

## 保持的约定

- Key 仅保存在页面内存，不写入数据库、备份或日志。
- 网络请求只直连 DeepSeek 官方 API，不引入代理或统计 SDK。
- 文本按纯文本渲染；导入预览后才持久化。
- 更改目录、品牌或构建方式时，保留旧存储和备份标识的兼容性。
- 数据访问、基础导出、删除和安全保护始终免费。
- `LICENSE` 保留原版权声明，不随品牌重命名删除原署名。
