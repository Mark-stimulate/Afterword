# 数据、隐私与备份

[返回首页](../README.md) · [安全报告](../SECURITY.md)

| 数据 | 保存与发送方式 |
| --- | --- |
| 对话、历史版本、处理后图片、来源引用、记忆卡、模板 | 保存在当前浏览器、当前站点的 IndexedDB；未作应用级数据库加密。 |
| API Key | 默认未加密自动保存到当前站点 localStorage，刷新后自动恢复；用户可选择密码加密保存，刷新后解锁。此前已保存的密文保持加密状态。测试连接、查询余额、发消息、文件上传 / 删除、语音转写与朗读时发送到 DeepSeek 官方 API。 |
| 外观、声音偏好与授权 | 当前站点 localStorage；不含聊天正文，也不随聊天备份导出。 |
| 聊天文档附件 | 选择后先留在页面，发送时直传 DeepSeek Files API，最长 30 天过期；可能按页收取解析费用。原文件不存入本站数据库或备份，仅保存名称、大小、解析方式、引用 ID 和到期时间。 |
| 导入文件 | 在浏览器中解析；导入本身不调用 API。 |
| 模型请求 | 浏览器直连 `api.deepseek.com`，包含 Key、当前消息及实际选中的上下文；思考与联网同时开启时，选中历史的思考字段也会回传。 |
| 录音与朗读 | 录音先在页面内存；确认转写后直传官方。点击朗读即发送对应回复文字并生成、播放音频；音频不写入 IndexedDB 或备份，切换对话、重新渲染消息或关闭页面后释放。 |
| 联网工具 | 默认关闭；开启后由 DeepSeek 执行搜索与网页读取。来源只显示文字链接，不自动加载外站图片。 |
| 网页访问 | 托管方提供静态资源，可能按其配置记录访问 IP、时间等元数据。 |

应用没有代理转发、广告统计 SDK 或账号云同步。上述描述针对本仓库代码；第三方改版与托管环境需要自行核实。

## 加密备份不等于整个浏览器已加密

加密导出使用 PBKDF2-SHA256（250000 次）、随机盐与 AES-256-GCM。备份密码至少 10 个字符，不含 API Key。请使用独立密码并妥善保存；项目不能找回密码。

日常数据库仍由浏览器保存，设备上能访问此浏览器的人可能看到记录。清理浏览器数据、换域名或使用临时浏览模式可能使记录不可访问。

## 你的控制权

查看、复制、删除记录、基础导出和加密备份始终免费。移除高级授权不会删除聊天或已有模板；已有模板仍可查看、复制、删除和备份。

## 兼容性

产品曾用名「续页」。内部 `xuye` 存储、备份和授权标识保留，用来兼容原记录；它们不是网络上传地址。更改显示名称不会主动迁移或删除数据。

开源便于检查，但不代表独立审计已经完成。发送给 DeepSeek 的数据由其服务条款处理。

## 图片与备份版本

新加图片在浏览器中缩放、重新编码后保存，不保留原图的 EXIF 等元数据；像素中已有的文字、面孔等内容仍会保留。每轮最多 4 张，每张处理后最多 1 MiB。历史与本轮最多发送 8 张，发送前可预览范围。

0.3.0 导出的聊天备份为 v2，包含处理后图片和来源引用，仍可读取旧版 v1 备份。较旧的拾语版本无法读取 v2；请先升级。加密外层仍为原 AES-GCM v1 封装。Key、原始录音和生成的音频不会写入备份。

录音或转写途中关闭窗口、朗读途中点击停止、切换对话或关闭页面会取消相应操作，但已发生的官方用量仍可能计费。

深度思考默认关闭。API 返回的思考字段保存在当前对话中，并进入自有聊天备份；界面仅显示思考进度，官方 ZIP 的思考过程仍不导入。

本机 Key 密文使用 PBKDF2-SHA256（60 万次）与 AES-256-GCM。解锁密码不保存，Key 不进入聊天备份。清理网站数据会删除密文；加密保存不能防止已解锁页面中的恶意扩展或脚本读取 Key。

每次发送会将设备报告的当前日期、时间和时区加入模型上下文，供现实时间问题参考；不读取定位，也不会因此自动开启联网搜索。可在「查看发送内容」中核对。设备时钟错误仍会影响结果。

## 文档附件与官方存储

文件问答与「导入旧对话」是不同操作。选中的附件直接加入草稿，只有在点击发送后才上传；草稿中会显示上传与解析计费提示。PDF / Word / PPT 可选只读文字或同时解析图表，表格与电子书由官方转换；最多每轮 4 个文件，每个 20 MiB。原文件可能含作者等元数据，上传前请自行检查。

文件属于上传时的 DeepSeek 账户。换 Key 所属账户、文件过期或删除后，旧引用可能无法读取；过期或本机已标记删除的附件在后续请求中用不可读取说明代替。文档完整内容及其图片会参与模型上下文，不计入本机 4 万字符的文本历史上限，仍受官方上下文、文档和图片限额约束。

点击消息中的文件可查看到期信息并请求从官方删除；需要上传账户的 Key，并再次确认。删除会使其他对话中的同一引用失效。删除本机聊天、清除网站数据或移除草稿附件，不会自动删除官方文件；无论是否发送成功，解析成功的文件仍可能存到到期日并计费。中断的请求不能保证取消官方解析。官方不支持下载文档原件或解析结果，请自行保留原件。

编辑自己的消息并重新发送时，当前分支会从修改处继续，原来的消息与后续回答留在本机历史版本中。版本随自有备份保留，不会自动进入新请求；删除整段对话会一并删除其本机历史版本。

未加密保存的 Key 可被能访问此浏览器或本站脚本的人读取；加密选项只保护保存状态，解锁后的页面仍可使用 Key。两种方式都不进入聊天数据库、聊天备份或应用日志；清理网站数据会删除保存的 Key，换域名或浏览器不会自动迁移。

回复 Markdown 仅由本地打包的解析器分词，再按允许的节点创建页面元素。原始 HTML 不执行，链接仅允许 HTTP(S)，外部 Markdown 图片不自动加载；原文和已有聊天记录不因显示排版而改写。
