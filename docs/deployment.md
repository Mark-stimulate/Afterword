# 自行部署与免费授权

[返回首页](../README.md) · [开发说明](development.md)

这份指南帮助你自行部署拾语，使用仓库提供的免费 license 解锁高级功能。基础功能不需要授权；DeepSeek API 的费用由你自己的账户承担。

## 在本机使用

安装 Node.js 22 或更新版本，下载源码后，在仓库根目录运行：

```bash
npm run community
cd community
npm start
```

打开 `http://127.0.0.1:4173`。服务器只监听本机；请勿直接双击 HTML 文件。

## 免费解锁高级功能

打开「设置与管理 → 高级功能 · 授权」，下载 **社区免费授权.license**，再选择该文件并点击「验证并解锁」。也可以从仓库的 [examples 目录](../examples/社区免费授权.license) 下载。

授权在浏览器内离线验证并保存；无需注册或上传聊天。没有导入 license 时，仍可使用全部基础功能。移除授权后，高级操作关闭，已有模板仍能查看、复制、删除和备份。

社区免费授权无到期日，适用于 0.x 版本，仅用于自行部署的社区验签配置；不能用于运营者提供的站点。

## Cloudflare Pages

连接自己的 GitHub 仓库，使用以下配置：

| 设置 | 填写内容 |
| --- | --- |
| 框架预设 | None |
| 根目录 | 仓库根目录 |
| 构建命令 | `npm test && npm run build:community` |
| 输出目录 | `dist` |
| Node.js | 环境变量 `NODE_VERSION=22` |

构建时不需要 API Key。不要把用户 Key 添加到环境变量或 GitHub Secrets；用户在自己的浏览器页面填写 Key。

`dist` 仅包含网站静态文件和响应头配置。源码目录 `src` 不是最终发布目录。Pages 会读取生成的 `_headers`，设置 CSP 等响应头。默认 `noindex` 仅请求不收录，不是访问密码。

## 1Panel 或其他静态托管

在源码仓库根目录运行：

```bash
npm test
npm run build:community
```

将 **dist 内的文件** 上传到网站运行目录，使 `index.html` 直接位于网站根目录。启用有效 HTTPS。无需配置 Node 服务、数据库或反向代理。

非 Pages 服务器通常不会识别 `_headers`，需在服务器中配置对应响应头。不要把整个源码仓库当成网站运行目录。

## 图片与语音

浏览器录音需要 HTTPS 和麦克风权限。从旧部署更新时，同步更新静态文件与 `_headers`，确保 `media-src` 允许本地 `blob:` 音频，工作线程脚本来自本站。无需添加其他第三方域名。

## 更新与域名

更新前先导出加密备份，保留可回退的版本。保持同一协议、域名、浏览器和存储标识时，更换托管不需要主动迁移记录；预览地址和其他域名的数据是隔离的。

使用新域名时，请先从旧域名导出，再在新域名恢复，并重新设置 Key、主题等本地偏好。不要立即把旧域名强制跳转，也不要清除网站数据。

真实手机网络、浏览器跨域策略、真实 ZIP 导出和余额查询需要实际验证；构建成功不能代替这些检查。
